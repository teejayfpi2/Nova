# AGENTS.md

Repository guidance for AI agents working in this project.

## What this is

Nova is a self-hosted personal assistant: a FastAPI server ("the brain"), a real
installable **Android app** (`android/`), a **desktop app** for laptops
(`desktop/`, Electron), plus an installable PWA front end, plus small device
agents that let it control a phone and a laptop. It can also delegate whole jobs
to autonomous OpenHands agents. See `README.md` for the user-facing guide.

## Layout

- `assistant/agent.py` — the reasoning loop (prompt → tool calls → answer). Streams events.
- `assistant/llm.py` — OpenAI-compatible client. Supports custom headers
  (`extra_headers`) and the OpenHands managed key proxy via
  `OH_LLM_API_KEY_REFRESH_URL` / `OH_LLM_API_KEY_REFRESH_HEADERS`.
- `assistant/openhands.py` — client for an OpenHands agent server; powers the
  `delegate_task` / `check_task` / `research_topic` / `build_software` tools.
- `assistant/memory.py` — SQLite long-term memory (facts, notes, todos, reminders, history).
- `assistant/tools/__init__.py` — `@tool` decorator + registry that builds JSON schemas.
- `assistant/tools/builtin.py` — all built-in tools.
- `assistant/bridges.py` — `LocalBridge` (in-process, pyautogui/xdotool) and
  `RemoteBridge` (HTTP long-poll to a device agent).
- `assistant/server.py` — REST + WebSocket + static hosting.
- `bridges/phone_agent.py`, `bridges/laptop_agent.py` — Python device agents.
- `android/` — Kotlin Android app; sources are generated by
  `scripts/gen_android_sources.py`. Build with `scripts/build_apk.sh`.
- `desktop/` — Electron laptop app; sources are generated by
  `scripts/gen_desktop_sources.py`. `desktop/agent.js` is the device agent that
  runs inside Electron and executes desktop commands.
- `scripts/fake_openai_server.py` — offline stub model for tests and hacking. It
  switches scripted tool calls based on keywords in the user message: "type"
  (device), "open" (url), "delegate" (delegation), otherwise memory.

## Commands

```bash
python -m pytest tests -q                      # 22 tests, no network needed
python -m assistant.cli chat                   # interactive
python -m assistant.cli serve                  # run the server
python scripts/fake_openai_server.py 9099 &    # stub model
./scripts/build_apk.sh                         # build the Android APK
cd desktop && npm install && npm start         # run the desktop app
cd desktop && npm run dist                     # build desktop installers
```

## Conventions

- Tools: decorate a function with `@tool`; first docstring paragraph is the
  description; document params as `name: description` lines. Add `ctx: ToolContext`
  when the tool needs memory/settings/bridges.
- Device tools take `target="laptop"|"phone"` and route through `ctx.bridge(target)`,
  falling back to local execution.
- The agent loop is **blocking**. Never call it directly from an async route on the
  event loop — use `asyncio.to_thread` (see `/api/chat`), or device-bridge polling
  will deadlock. There is a regression test for this.
- Android and desktop sources are **generated** by the `gen_*_sources.py` scripts.
  Edit the generator, not the generated files, then re-run it.
- Keep dependencies in `requirements.txt` and `pyproject.toml` in sync.

## Gotchas

- `python-multipart` is required for the audio upload endpoint.
- Voice is optional and degrades: STT `openai`→`faster-whisper`→`whisper`→`vosk`;
  TTS `edge-tts`→`openai`→`pyttsx3`→`say`→`espeak`. `ffmpeg` is needed to convert
  browser audio to WAV for local Whisper.
- Web search scrapes DuckDuckGo's **lite** endpoint (the html one serves an
  anti-bot page to plain clients) with a browser user agent.
- `data/memory.db` is the whole long-term memory; it is gitignored.
- The OpenHands agent-server `/v1/chat/completions` endpoint runs OpenHands' **own**
  agent and ignores a `tools` parameter. It is fine as Nova's *brain* (plain chat),
  but delegation must go through the conversations API (`assistant/openhands.py`),
  not through that endpoint with custom tools.
- The OpenHands managed LLM proxy (`llm-proxy.app.all-hands.dev`) is policy-locked:
  it 403s direct calls with a session key. Use a local agent server for delegation,
  and either a normal provider or the agent-server chat endpoint as the brain.
